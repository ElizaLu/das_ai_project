# 整体思路
**如果现在标注很粗、空间位置不准、拓扑又复杂，先做“时间一维 + 多通道局部输入”的模型，往往比硬上二维更稳。
如果你能把光纤按物理路径展开成稳定的“距离轴”，并且能给出较可靠的事件位置，那二维模型上限更高。**

1D的缺点

- 会丢空间信息：事件可能在 70 通道附近传播到相邻通道，单通道会看不全。
- 对复杂事件不够鲁棒：像车辆、列车、多人活动、跨段事件，通常不是单点能完全描述的。

# 采集数据时注意
- 一定要采无事件数据，而且要采得足够多。
- 一定要采“硬负样本”，就是那些容易和事件混淆的正常片段，比如：
 -风吹
 -小动物
 -机械振动
 -设备背景噪声
 -其他非目标事件

### 一、DAS 异常检测任务

1. **类别不均衡问题优化**
   ![alt text](image.png)
   * 如图，由于当前 type 分类样本相对较少，损失函数反映出训练时存在明显类别不平衡问题；
   * 计划通过**调整 loss 权重（提升 loss_type 权重）**，优化模型对少数类别的识别能力；
   * 重点关注指标：**type-level F1-score 提升**。

2. **多类型注意力机制优化**

   * 针对不同事件类型在空间分布上的差异，引入**多头注意力机制（multi-head attention）**；
   * 每个事件类型对应独立 attention head，以增强模型的判别能力与可解释性。

3. **通道定位能力增强**

   * 将模型输出的**通道注意力权重**与**原始通道编号进行映射**；
   * 实现从“是否发生异常”向“异常发生位置（空间定位）”的能力扩展。
